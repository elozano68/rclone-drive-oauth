# Privacy Policy

## Rclone Google Drive — Personal Integration

This project is a personal, non-commercial integration that uses rclone to synchronize files between Google Drive and a local Debian Linux computer.

### Data Access and Use

The application accesses Google Drive files only after the account owner explicitly authorizes access through Google OAuth. This access is used solely to synchronize files and folders selected by the user.

### Data Storage and Sharing

File transfers occur directly between the user's computer and Google Drive. This project does not operate an intermediary storage server, sell personal information, or share Google Drive data with third parties.

OAuth credentials and tokens are stored locally in each user's rclone configuration. Synchronization logs may contain file names and transfer information.

### User Control

Users can revoke the application's access at any time through their Google Account security settings. Local files and configuration can be managed directly on the user's computer.

### Disclaimer

This is an independent personal project and is not affiliated with or endorsed by Google.
