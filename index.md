# Rclone Google Drive

## Personal Google Drive synchronization

This is a personal project for synchronizing files between Google Drive and a Debian Linux computer using rclone.

The application uses Google OAuth to access only the Google Drive accounts explicitly authorized by their owners.

File transfers are performed directly between the user's computer and Google Drive. This project does not operate an intermediary file-storage server.

This is a personal, non-commercial integration and is not affiliated with Google.
